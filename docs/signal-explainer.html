Signal Primitives

Interactive explorer — signal() · computed() · effect()

signal — reactive state
computed — derived value

◉
Signal

The source of truth. A signal holds a value that any number of computeds and effects can subscribe to. When you call .set(), all subscribers re-run automatically.

const count = signal(0);
count.get(); // read → 0
count.set(1); // write → notify
⬡
Computed

A lazily-evaluated derived value. It runs its function once and caches the result. Dependencies are tracked automatically — any signal read inside the function becomes a dependency. Re-runs only when dirty.

const doubled = computed(
  () => count.get() * 2
);
doubled.get(); // → 0, cached
▸
Effect

A side effect that runs immediately and re-runs whenever its dependencies change. Use it to update the DOM, log, or trigger any external action. Returns a dispose() to stop tracking.

const stop = effect(() => {
  el.textContent = doubled.get();
});
stop(); // dispose

Equivalent code
const celsius = signal(20);

// computed: lazy, cached, auto-tracks celsius
const fahrenheit = computed(() =>
  celsius.get() * 9 / 5 + 32
);

// effect reads computed (not signal directly)
effect(() => {
  const f = fahrenheit.get(); // triggers lazy eval
  updateIndicator(f);
});

// Chain: celsius.set → computed.invalidate → effect.run
celsius.set(37); // body temp — all three update

Multi-signal → Computed: dependency tracking

A computed automatically subscribes to every signal it reads during evaluation. Change either input below — the computed re-evaluates and the effect re-runs.

Equivalent code
const price    = signal(10);
const quantity = signal(1);

// computed reads BOTH signals — tracks both automatically
const total = computed(() =>
  price.get() * quantity.get()
);

effect(() => {
  renderReceipt(price.get(), quantity.get(), total.get());
});

// Either signal triggers the chain
price.set(25);    // → total recomputes → effect re-runs
quantity.set(3); // → same chain
Under The Hood
How Elements Get Wired: Registration

The magic is automatic dependency tracking — no event listeners, no explicit subscriptions. When an effect runs, it sets a module-level variable currentEffect. Any signal.get() called during that run sees it and adds the effect to its subscribers Set. Step through to watch each line of src/signal.js execute.
