# Data dictionary — `reviewer_activity_daily`

The gold-only aggregate behind the per-Reviewer and Reviewer Manager Report
Feeds. It belongs to the `reviewer_activity` Reporting subject and is rebuilt
from the Sync subject's current `case_current` table. One row represents one
Reviewer, one local calendar date, and one Case Type with at least one
reportable, non-void Case.

The Python contract is
[`pipelines/reviewer_activity/schema.py`](../pipelines/reviewer_activity/schema.py);
the builder is
[`pipelines/reviewer_activity/gold.py`](../pipelines/reviewer_activity/gold.py).

## Part B — Field dictionary

| Field | Source column | Type | Nullable | Value rules | Description | Example | Sensitivity | Notes |
|-------|---------------|------|----------|-------------|-------------|---------|-------------|-------|
| `reviewer_account` | `assigned_reviewer_name` | `str` | No | — | Lower-cased bare account of the Reviewer assigned to the Case. | `a.khan` | PII | The claims prefix and domain segment are removed; display names are resolved by the consumer. Rows without a usable account are omitted. |
| `reportable_date` | `reportable_at` | `date` | No | — | The local calendar date on which the Case's reportable instant falls. | `2026-08-10` | None | `reportable_at` is parsed as a UTC instant and converted through `tools.observability.timestamps.local_date`. |
| `case_type` | `case_type` | `str` | No | — | The Case Type slug. | `complaints` | None | A slug is a key, not display copy. |
| `count` | derived | `int` | No | `Range(minimum=1)` | Number of current, non-void Cases in the grain. | `4` | None | The table is sparse: no row means no work for that combination. |
| `as_of_utc` | `case_current.as_of_utc` | `str` | No | — | The UTC instant at which the Sync current-state snapshot was described. | `2026-08-10T06:00:00+00:00` | None | One source snapshot instant is propagated to every emitted row; it is not generated by this aggregate's clock. |

## Part C — Row checks

None. The group-by produces the declared grain, so no uniqueness gate is
attached.

## Part D — Quarantine & data quality

- Cases with `status == "Void"` do not contribute to the count.
- A missing or blank Reviewer account, a missing `reportable_at`, or a missing
  Case Type cannot form the declared grain and is omitted from the sparse
  aggregate. The Sync `case_current` schema remains the boundary for the source
  row contract.
- Conflicting or invalid `as_of_utc` values in a non-empty Sync snapshot fail
  the aggregate rather than mixing two snapshots into one table.
