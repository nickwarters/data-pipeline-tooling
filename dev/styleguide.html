Overview

#overview

Utilitarian
Precision.

A compliance and quality-assurance tool for financial services teams. Dense, data-forward, every pixel justified. Not enterprise software boring — purposefully sharp. Use this document as the decision test: if a proposed element feels decorative without function, it doesn't belong.

Non-corporate Functional Bold Fintech WCAG AA Keyboard-first Dark-mode system

Design principles

Information first

Data is the hero. Chrome is the villain. Every visual element must earn its place by making information clearer.

Deliberate contrast

One accent color. Signal red. Used only when something genuinely demands attention — a failure, an overdue case, a primary action.

Keyboard parity

Every workflow achievable with keyboard alone. Tab order is logical. Focus rings are unmistakable. Arrow-key navigation in lists and tables.

Motion

#motion
--cora-duration-fast
100ms
Hover states, button presses, focus ring appearance
--cora-duration-base
200ms
Drawer open/close, modal entrance, toast slide-in
--cora-duration-slow
350ms

All transitions respect prefers-reduced-motion: reduce — durations collapse to 1ms. Never animate layout-affecting properties (width, height, top, left) — prefer transform and opacity only.

People Picker

#people

PeoplePicker() — live type-ahead (mock directory)

Type a name (try smith, jones, or wei) to search the mock directory. Selecting a result calls the onSelect prop with the bare account name. With no matches, a free-text fallback offers the typed text as a raw account. The picker is a pure view function — state lives outside it and every keystroke re-renders through render(), which is what keeps the caret in place.
